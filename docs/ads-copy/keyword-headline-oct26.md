- **מודעה חדשה ולא עריכה של הקיימת:** Edit ← Copy ← Paste לאותה קבוצה, עם שני הסימונים
  "Pause new ads after pasting" ו-"If ad already exists in destination, create duplicate".
  את העותק המושהה עורכים, שומרים ומפעילים. כך אין רגע בלי מודעה מאושרת.
- הדבקת `{KEYWORD:טקסט}` לשדה הכותרת מזוהה כהוספת מילת מפתח: המונה סופר רק את ברירת המחדל

- עמוד האזור של חיפה נקרא "פסיכולוגים ומטפלים בקריות ואזור חיפה" (`REGION_SEO_FOCUS`), ורוב
